# Odoo Landing Page

Landing page statis berbahasa Indonesia untuk layanan konsultasi dan implementasi Odoo ERP.

## Publikasi
Website dipublikasikan melalui GitHub Pages menggunakan GitHub Actions. Di repository, buka **Settings → Pages** dan pastikan **Source** disetel ke **GitHub Actions**. Setelah workflow berhasil, situs tersedia di:
https://goyugo.github.io/odoo-landing-page/

## Kustomisasi sebelum digunakan
- Ganti `halo@domainanda.com` pada `index.html` dengan email bisnis yang benar.
- Ubah branding `odoo. partner` sesuai identitas bisnis Anda.
- Tambahkan nomor WhatsApp, logo, alamat, dan informasi legal jika diperlukan.

Catatan: ini landing page statis, bukan instalasi aplikasi Odoo ERP. Nama dan merek Odoo merupakan milik pemiliknya masing-masing; sesuaikan penggunaan merek dengan status kemitraan Anda.
